segmentation) and **supervised learning** (churn prediction) to help a telecom business
identify *who* their customers are and *which ones* are at risk of leaving — with an
interactive Streamlit web app to explore the results live.

## Problem Statement

Businesses lose significant revenue when they can't identify which customers are likely to
leave (churn) or understand the distinct behavioral groups within their customer base. This
project:

1. **Segments customers** into meaningful groups based on behavior using unsupervised learning
2. **Predicts churn risk** for individual customers using supervised learning
3. **Combines both** to show which customer segments need retention attention most, backed by
   a live web dashboard

## Dataset

[Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) —
7,043 customers, 21 features covering demographics, account information, subscribed services,

## Methodology

1. **Data Cleaning** — fixed blank `TotalCharges` values, dropped non-predictive ID column, encoded target variable
2. **Exploratory Data Analysis** — churn distribution, tenure/charges patterns, contract-type impact
3. **Unsupervised Learning (Segmentation)**
   - Scaled behavioral features (tenure, monthly charges, total charges)
   - Determined optimal cluster count via **Elbow Method** + **Silhouette Score**
   - Applied **K-Means**, validated against **Hierarchical Clustering**
   - Visualized segments with **PCA**; profiled each segment's characteristics
4. **Supervised Learning (Churn Prediction)**
   - One-hot encoded categorical features
   - Balanced classes with **SMOTE** (applied to training set only)
   - Trained and compared **Logistic Regression**, **Random Forest**, and **XGBoost**
   - Tuned the best model with **GridSearchCV**
   - Extracted feature importance to identify top churn drivers
5. **Evaluation** — Precision, Recall, F1-Score, ROC-AUC (not accuracy alone, since churn is imbalanced ~26%/74%)
6. **Integration** — cross-analyzed churn rate by segment to flag high-risk customer groups
7. **Streamlit Web App** — interactive exploration, live churn prediction on custom customer profiles

## How to Run

### 1. Clone the repository
```bash
git clone https://github.com/ezhil1402/Customer-Churn-Prediction-Dashboard.git
cd Customer-Churn-Prediction-Dashboard
```

### 2. Create and activate a virtual environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```
> **Common mistake:** installing packages *before* activating the venv, or opening Jupyter
> with a different kernel than your venv. Always confirm with `import sys; print(sys.executable)`
> in a notebook cell that the path points inside your `venv` folder.

### 3. Install dependencies (into the activated venv)
```bash
pip install -r requirements.txt
```

### 4. Run the notebook
```bash
jupyter notebook Capstone_project.ipynb
```
Run all cells top to bottom. This generates every file inside `/reports` that the dashboard depends on.

### 5. Launch the Streamlit web app
```bash
streamlit run dashboard.py
```
Opens automatically at `http://localhost:8501`.

## Kaggle API Setup

Only needed if you want to use **Option A** (official Kaggle source) instead of the automatic
GitHub fallback.

1. Go to [kaggle.com](https://kaggle.com) → profile picture → **Account**
2. Scroll to **API** → **Create New Token** → downloads `kaggle.json`
3. Place it at:
   - Mac/Linux: `~/.kaggle/kaggle.json`, then run `chmod 600 ~/.kaggle/kaggle.json`
   - Windows: `C:\Users\<YourName>\.kaggle\kaggle.json`
4. Install the CLI: `pip install kaggle`

> `kaggle.json` contains personal credentials and is already excluded via `.gitignore` —
> never commit it.
